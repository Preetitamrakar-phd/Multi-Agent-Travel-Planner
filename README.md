# **Travel Planning Multi-Agent system**

An intelligent system that coordinates multiple specialized agents to search flights, hotels, plan itineraries, and provide personalized travel recommendations.

Tavily is an AI‑optimized search engine built for agents and RAG workflows, while SerpApi is a real‑time API that scrapes and delivers structured search results 
from Google and other engines. 
Both are used to give AI systems or applications reliable, up‑to‑date web data without manual scraping.

Tavily: A search engine API designed specifically for AI agents and LLMs.
SerpApi: A Google Search API (and multi‑engine API) that lets developers pull live search results directly in JSON format.
